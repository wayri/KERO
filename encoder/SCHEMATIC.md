# Native encoder schematic

Open `Encoder.kicad_pro`, then `Encoder.kicad_sch` with KiCad 10. The root hierarchy links power, three delay banks (4 + 4 + 3 stages), and the eleven-input majority decoder. Each delay stage is drawn with its timing capacitor, timing resistor, and three threshold resistors. Hierarchical labels carry the supply rails and stage outputs between sheets; named local nets join the short wires within each functional circuit.

The circuit implements the custom eight-symbol PWM code in `../encoded-model/design.json`, repeating `hello world`. It uses twelve amplifier channels in three TLV9044IPWR packages, one CR2032 holder, and red/green output indication. The encoded output is electrical and visible; this board contains no radio. The original two-amplifier blinker remains separately at the repository root.

Project text variables define all timing resistor values, common timing/bypass capacitance, summing/divider/LED resistance, and the amplifier value/manufacturer/MPN. Native XML export expands these expressions. Board fields must contain the expanded values for KiCad's board/schematic parity check. `design-intent.json` records both scoped native net names (`pins`) and their simulation names (`logical_pins`).

`tools/build_encoder_schematic.py --validate` (run from the repository root with the installed KiCad Python) regenerates the hierarchy and checks it with KiCad CLI. It preserves existing project settings while restoring the defined variables and agreed default class rules. Native checks export six SVG pages, the XML netlist, and ERC JSON. The validation receipt also verifies all 194 physical terminal assignments and every fitted part's expanded value, footprint, manufacturer, and MPN. `bom.csv` contains 79 fitted parts; the battery row describes the holder, and the cell is a separate assembly consumable.

The generated values come from the simulation-bound specification. Changing a project variable demonstrates a CAD edit, but invalidates the corresponding behavior evidence until that revision is simulated again. Exact passive and LED MPNs remain open; generic `Select to specification` fields are intentional. Timing capacitor C0G/1% availability in the selected package still needs procurement verification. High-value resistors use larger footprints: 0402 through 1 MΩ, 0603 above 1 MΩ through 2 MΩ, and 0805 above 2 MΩ. Native ERC is not a proof of oscillator startup, tolerance performance, battery life, or manufacturing readiness.

`evidence/schematic-validation.json` binds the final schematic, symbol library, project variables/rules, and generator by SHA-256. The recorded KiCad CLI commands completed successfully; this environment reports denied registry-setting writes in stderr. No registry change was needed for export or ERC. PCB routing and DRC acceptance are tracked separately.
